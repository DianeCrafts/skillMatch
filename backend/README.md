# SkillMatch Backend

## Services
- api-gateway
- auth-service
- profile-service
- job-service
- application-service
- file-service
- notification-service

## Local prerequisites
- Java 21
- Maven
- PostgreSQL
- Docker Desktop
- pgAdmin
- IntelliJ

## Local setup
1. Create the PostgreSQL databases
2. Fill `.env`
3. Start Redis with Docker Compose
4. Run services from IntelliJ
